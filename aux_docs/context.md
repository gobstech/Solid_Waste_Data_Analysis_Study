# Contexto do projeto

Um grupo de pesquisadores da cidade de São Paulo deseja, a partir dos dados sobre resíduos sólidos reunidos em uma tabela disponibilizada pela prefeitura, analisá-los para propor meios mais eficientes de gerenciamento de lixo nas futuras políticas públicas da cidade.

Este grupo de pesquisadores reuniu como variáveis qualitativas: 
- Região da cidade onde foi feita a coleta;
- Tipo de resíduo;
- Origem do resíduo (setor gerador);
- Método de Destinação;

E como variáveis quantitativas:
- Massa Coletada (kg);
- Densidade aparente  do  resíduo  (in natura) (kg/m3);
- Teor  de Umidade (%);
- Distância até Destinação  (km);
-  Custo  da  coleta  /  transporte (R$/ton);
- Índice de Reciclabilidade (%);
- Poder calorifico (poder de aproveitamento) (MJ/kg).

O grupo de pesquisadores, depois de muita análise, escolheu como variáveis:
- 1 Qualitativa
- Quantitativa 1
- Quantitativa 2

As ferramentas que o grupo utilizou para fazer a análise foram:

- Google Colab
- Python
- Visual Studio Code
- Excel
